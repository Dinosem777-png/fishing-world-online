# Fishing World Online 3.0

Браузерная мобильная версия без внешних библиотек.

## Новое в 3.0
- 7 видов рыбы, включая мифического осетра.
- 4 локации с требованиями по уровню и стоимостью открытия.
- 5 удилищ, 5 лесок, 5 катушек и 5 наживок.
- Улучшенная мини-игра вываживания: натяжение, энергия рыбы, риск обрыва.
- XP, уровни, монеты и репутация.
- Ежедневные задания.
- Кубок рыболова с локальным рекордом.
- Энциклопедия рыб.
- Погода и часы.
- Автосохранение в localStorage.
- Полностью адаптивный интерфейс.

## Запуск
Откройте `index.html` в браузере.

## Важно
Глобальные аккаунты, реальный общий онлайн-рейтинг, облачное сохранение и PvP требуют backend/API. Эта версия работает автономно в браузере.
