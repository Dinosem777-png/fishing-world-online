# Рыболовная Одиссея 🎣

Новая мобильная браузерная игра, рассчитанная прежде всего на вертикальный экран Android и iPhone.

## Возможности
- Заброс, поклёвка и мини-игра вываживания с индикатором натяжения лески.
- Разные виды рыб, вес улова, награды, опыт и уровни.
- Несколько водоёмов с требованиями к уровню и стоимости открытия.
- Наживки, улучшение удочки, лески и катушки.
- Садок, история уловов, энциклопедия, задание и личный рекорд.
- Сохранение локального прогресса в браузере.
- Поддержка установки на главный экран и базовое кэширование.

## Запуск
Опубликуйте репозиторий через GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## Ограничения текущей версии
Это одиночная игра: общий онлайн-рейтинг, учётные записи и синхронизация между устройствами требуют отдельного сервера и пока не реализованы. Для корректного офлайн-запуска сначала откройте игру онлайн, чтобы файлы закэшировались.
